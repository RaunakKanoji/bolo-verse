# AI workflow rules

Provider keys remain server-only. A key being present does not establish model availability, billing access or implemented generation. The public creative capability catalog advertises no available media generation until authorization, durable jobs, provider invocation, object storage, metadata and recovery are connected.

Re-verify primary provider documentation and account capabilities before Phase 3. The [dated research](../docs/shape-studio/native-provider-research.md) records the current Gemini/Sarvam evidence and limitations. Do not infer image/video/3D support from a text or speech adapter. Hide unsupported negative prompt/seed/model settings.

Existing XR assistant proposals remain bounded, permission checked and explicitly applied. Important scene changes require user acceptance; destructive or externally visible actions need confirmation. Voice capture requires explicit consent, visible state and owned-resource cleanup. No raw command audio persistence or secret-bearing logs.

The current private draft API stores user-authored prompt text after explicit Save. It neither invokes an AI provider nor queues work. Future AI conversations, reviews and generated assets require the same project/tenant authorization as other private data.
