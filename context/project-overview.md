# Shape Studio

Shape Studio is a creative production workspace for creators and MSME clients. The intended workflow runs from brief and concepts through production, review, approval and delivery. Web and the native visionOS foundation operate on the same authorized project contracts.

The current delivery extends the shared foundation and web playground with the native SwiftUI/RealityKit app requested in the [Spatial specification](../docs/shape-studio/SPATIAL_MASTER_SPEC.md). The repository also contains projects, a spatial browser studio, a text/speech assistant and local image/recording tools; preserve these capabilities. See [native architecture](../docs/shape-studio/native-architecture.md) and [validation](../docs/shape-studio/native-validation.md) for implemented native behavior and remaining acceptance gates.

Start with the [audit and implementation plan](../docs/shape-studio/phase-0-plan.md), [architecture](architecture-context.md) and [progress tracker](progress-tracker.md). The older BoloVerse/XR specifications remain historical references; the latest Shape Studio brief governs this phase. Existing GitHub repository and URLs remain compatible.
