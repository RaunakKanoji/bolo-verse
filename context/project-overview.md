# Shape Studio

Shape Studio is a creative production workspace for creators and MSME clients. The intended workflow runs from brief and concepts through production, review, approval and delivery. Web and the native visionOS foundation operate on the same authorized project contracts.

The current delivery establishes the Phase 1 monorepo foundation from the [unified platform prompt](../docs/product/UNIFIED_PLATFORM_SPEC.md), reusing the web/backend, browser XR and native SwiftUI/RealityKit implementations. The [system overview](../docs/architecture/system-overview.md) defines real package boundaries, current data/contracts, gaps and later milestones. Preserve all existing features; the prior native implementation and verification remain documented separately.
